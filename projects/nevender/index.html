A simple demo of Virtual Geometry in THREE.js

Prove of concept of virtual geometry for non-WebGPU Browsers

What does the Demo Feature?

The demo features custom simplification, meshletization, DAG-building, grouping and merging of meshlets, as well as travresal of the resulting DAG and building of a geometry based on the cut. It also supports custom attributes and textures.
Currently building the DAG takes quite a while, because the meshletizer is utilizing BFS, as do the grouping algorithms. Because I wasn't able to create a traversal algorithm in WebGL this remains a prove of concept that has no performance increase for real THREE.js scenes.

What does the Demo NOT Feature?

In order to be practical for efficient use in THREE.js one main component needs to be optimized: The DAG traversal.
All other computations can be done offline and loaded at runtime, such as the building of the DAG.

Optimizing the DAG traversal is very challenging as it means hundreds of computations in parallel for large meshes. With JavaScript this is only manageable to a certain degree.
A real solution would therefore need to utilize the GPU, to be specific WebGL or WebGPU.
As Virtual Geometry was already implemented for WebGPU (albeit at the time standalone not for THREE.js) I tried implementing Virtual Geometry in WebGL, but soon gave up, because the constraints of WebGL where too restrictive. An implementation in WebGL, would mean a significant jump in the number of Devices, supporting Virtual Geometry in the Browser. This is why this Demo does not feature a WebGL-powered traversal.

Where can I try it out?

You can see the demo here.

How do I use the Demo?

First you need to wait for a while till the DAG traversal has finsihed and the geometry becomes visible on the screen. By moving the upper slider you can change the distance to the geometry and see the resulting changes in quality on the left side, as well as the changes in Triangle count on the right side in the window dubbed "TRIS". The lower slider changes the threshold of how high the qualit should minimally be.
